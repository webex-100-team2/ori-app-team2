# 推し活カレンダー 企画まとめ

## コンセプト

推し活の **予定** と **写真** を、カレンダーでまとめて管理できるアプリ。

## 解決したい困りごと

- **日程が管理しきれない**：ライブ、発売日、配信、申込締切などがあちこちに散らばっていて、見逃してしまう
- **写真が多すぎる**：現場写真やグッズ写真がカメラロールに埋もれて、どの日のものか分からなくなる

→ 予定をカレンダーに登録し、写真をその予定にひもづけることで、日程とアルバムを一緒に整理する。

## カレンダーでの見せ方

1つの予定を **推しのアイコン** で表示し、アイコンの **枠の色** で予定の種類を表す。

- アイコン → **誰の** 予定か
- 枠の色 → **何の** 予定か

例：赤い枠の🐰 = 🐰の推しの締切、ピンクの枠の🐰 = 同じ推しのライブ

1日に予定が多いときは、アイコンを2〜3個まで表示して、残りは「+2」のように数だけ出す。

### 予定の種類と色

| 種類 | 枠の色 |
|---|---|
| ライブ・イベント | ピンク |
| 締切 | 赤 |
| 発売日 | 黄 |
| 配信・放送 | 青 |
| その他 | グレー |

締切はいちばん見逃したくないので、目立つ赤にする。種類と色の対応はデータベースに入れず、コードの中に対応表として書いておく。

## 画面

### ① カレンダー（ホーム）

- 月表示のカレンダー
- 予定がある日に推しのアイコン（枠は種類の色）を表示
- 日付をタップすると、カレンダーの下にその日の予定リストが出る（別画面にしない）
- 「＋予定を追加」ボタン

### ② 予定の詳細

- タイトル、日時、場所、種類、チケットの状態、メモ
- その予定の写真を下に並べて表示
- 「写真を追加」「編集」「削除」ボタン

### ③ 予定の登録・編集

- 入力フォーム。新規登録と編集は同じ画面を使い回す
- 推しは、登録済みのアイコンを並べて「タップで選ぶ」形にする

### ④ 推しの登録・編集

- 名前とアイコンを入れるだけの小さい画面

### 画面の流れ

カレンダー → 日付をタップ → 予定をタップ → 予定の詳細 → 写真を追加

## 作る順番

1. **ステップ1（必須）**：予定のCRUD。これだけでスケジュール帳として成立する
2. **ステップ2**：写真のアップロードと、予定へのひもづけ
3. **ステップ3**：推しの登録と、カレンダーでのアイコン表示
4. **おまけ**
   - 締切が近い予定をトップで目立たせる（日付の比較だけでできる）
   - 全部の写真を新しい順に並べるアルバム画面（タップで元の予定に飛ぶ）
   - 推しのアイコンを絵文字から画像アップロードに変える

ステップ1が動いた時点で発表できる状態になるので、時間切れになっても大丈夫。

## 作りやすくするコツ

- **写真は予定の詳細画面からだけ追加できるようにする**。どの予定の写真かを選ぶ画面が要らなくなり、追加した時点で自動でひもづく
- **アイコンは最初は絵文字でOK**。画像を用意しなくていいので簡単
- **カレンダーの表示はライブラリを使う**（Webなら FullCalendar など）。自分で作るとかなり大変
- 登録画面と編集画面は同じフォームを使い回す
