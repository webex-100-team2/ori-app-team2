# カレンダー

ファイル：`src/pages/home/HomePage.jsx`
ブランチ：`home`

## 作るもの

- 月表示のカレンダーが出る。「前の月」「次の月」で月を切り替えられる
- 予定がある日のマスに、種類の色の丸い枠が出る（1 日 3 つまで。残りは「+2」のように数だけ）
- 日付を押すと、カレンダーの下にその日の予定が並ぶ。予定を押すと詳細に移る
- 「予定を追加」ボタンがある

使うデータ：

| コレクション | フィールド |
| --- | --- |
| `events` | `uid`・`title`・`date`（`"2026-12-24"` の形）・`time`（`"18:00"` の形）・`type`（種類） |

予定を保存するページ（予定の登録・編集）は、ほかの人が同時に作っている。できるまでは、Firebase のコンソールで手で入れたデータで確かめる。

今あるログインしている人の名前とログアウトのボタンは、消さずに残す。

## 手順

### ステップ 1：年月と、月の切り替えボタンを置く

「`year` と `month` という state を作る。最初は今日の年と月。`month` は 1〜12 で持つ」

「上に『2026年12月』のように `year` と `month` を出す。その左右に『前の月』『次の月』ボタンを置く。押すと月が 1 つ変わる。12 月の次は次の年の 1 月、1 月の前は前の年の 12 月にする」

- 今月が出て、ボタンで月が切り替われば OK
- 12 月で「次の月」を押すと、次の年の 1 月になれば OK

### ステップ 2：日付のマスを並べる

「`year` 年 `month` 月のカレンダーを、日曜始まりの 7 列で並べる。1 日より前の曜日のところは空のマスにする。上に日〜土の曜日を出す」

- 2026 年 12 月を出すと、1 日が火曜の列に、31 日まで並べば OK
- 2027 年 2 月（28 日まで）でも崩れなければ OK
- 参考：書き方の見本「CSS」（7 列に並べるのは `display: grid` で `grid-template-columns: repeat(7, 1fr)`）

### ステップ 3：確かめ用の予定を手で入れる

Firebase のコンソールで、`events` コレクションにドキュメントを 1 件足す。フィールドは次のとおり。

| フィールド | 型 | 値 |
| --- | --- | --- |
| `uid` | string | 自分の UID（コンソールの Authentication の画面でコピーする） |
| `title` | string | `横浜公演` |
| `date` | string | 今月のどこかの日（例：`2026-12-24`） |
| `time` | string | `18:00` |
| `place` | string | `横浜アリーナ` |
| `type` | string | `ライブ・イベント` |
| `ticket` | string | `当選` |
| `memo` | string | （空でよい） |
| `oshiId` | string | （空でよい） |
| `createdAt` | number | `1763450000000` |

- コンソールの `events` に 1 件入っていれば OK

### ステップ 4：自分の予定を取ってくる

「`events` という state を作る。最初は空の配列」

「`getEvents` という関数を作る。中身は、`events` コレクションから `uid` が自分のものを、`date` の古い順、同じ日の中は `time` の早い順に取得して、`events` を更新する」

「画面が表示されたときに 1 回だけ、`getEvents` を呼ぶ」

- 最初はブラウザのコンソールにエラーが出る。エラーの中のリンクを開いて「インデックスを作成」を押し、数分待つ
- `console.log(events)` で、ステップ 3 で入れた予定が出れば OK（確かめたら消す）
- 参考：書き方の見本「自分のものだけ取ってくる」、レシピ「読む」

### ステップ 5：予定がある日に丸い枠を出す

「マスの日付を `"2026-12-24"` の形の文字列にして、`events` の中から `date` が同じものを探す。見つかった予定 1 件ごとに、丸い枠を出す。枠の色は、`src/eventTypes.js` の `getTypeColor` に予定の `type` を渡して決める。枠の中は空でよい」

「1 日に 4 件以上あるときは、枠は 3 つまで出して、残りは『+2』のように数だけ出す」

- ステップ 3 で入れた日に、ピンクの丸い枠が出れば OK
- コンソールで同じ日に `type` が `締切` の予定を足すと、赤い枠が増えれば OK
- 同じ日に予定を 5 件にすると、枠が 3 つと「+2」が出れば OK
- 参考：書き方の見本「一覧と出し分け」

### ステップ 6：日付を押したら、その日の予定を並べる

「`selectedDate` という state を作る。最初は今日の日付を `"2026-11-26"` の形にした文字列」

「マスを押したら、そのマスの日付を `selectedDate` に入れる。押されているマスは色を変える」

「カレンダーの下に、`events` のうち `date` が `selectedDate` と同じものを、時間とタイトルで並べる。1 件もなければ『予定はありません』と出す」

「並べた予定を押すと、`/events/予定の id` に移る」

- ステップ 3 で入れた日を押すと、「18:00 横浜公演」が出れば OK
- 予定のない日を押すと「予定はありません」と出れば OK
- 予定を押すと「予定の詳細」の見出しのページに移れば OK
- 参考：書き方の見本「一覧と出し分け」「ページの移動」

### ステップ 7：「予定を追加」ボタンを置く

「『予定を追加』ボタンを置く。押すと `/events/new` に移る」

- 押すと「予定の登録・編集」の見出しのページに移れば OK
- 参考：書き方の見本「ページの移動」

### ステップ 8：見た目を整える

「マスを正方形に近い形にして、枠線で区切る。日曜の日付は赤、土曜の日付は青にする。今日のマスは背景の色を変える」

- カレンダーらしい見た目になれば OK
- 参考：書き方の見本「CSS」
